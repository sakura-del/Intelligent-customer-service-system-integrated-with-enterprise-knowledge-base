# 敏感词表：每行格式 `词|级别`
# 级别说明：
#   block —— 拦截：用户输入命中则拒绝处理，不进入 LLM 链路
#   warn  —— 替换：LLM 输出中命中则整词替换为 ***
#   mask  —— 打码：LLM 输出中命中则保留首尾，中间用 * 替代
# 注释行以 # 开头，空行忽略。无 `|` 的行默认 warn 级。
# 以下均为温和示例词，仅用于验证过滤流程，非真实敏感内容。

# ===== block 级：违法广告类示例 =====
代开发票|block
办假证|block
出售身份证|block

# ===== warn 级：不当用语示例 =====
笨蛋|warn
白痴|warn
垃圾话|warn

# ===== mask 级：需打码的词汇示例 =====
手机号码|mask
银行卡号|mask
订单编号|mask
